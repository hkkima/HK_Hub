## P3 — 중복·사본 드리프트

- **미러 계약 검증**: Gamble 6종 ✅(유일하게 테스트+CI 가드) · Stock market/events/dpcurve ✅ 일치하나 **가드 없음**(Stock CI 는 테스트 자체를 안 돌림) · auth 사본 6벌 로직 동일하나 GameHub 만 함수명이 다른 재구현(`participantId`), 골든 테스트는 Hub·Gamble 에만.
- **auth 정본 주석 드리프트**: 정본(Hub)이 "5앱"이라 쓰고, 사본들은 정본 표기가 제각각이거나 없음.
- **firebase.js 6벌**: 실질 드리프트 = 기본 리전(`us-central1` 4벌 vs `asia-northeast3` 2벌) + `HK_Stock/.env.example` 이 틀린 리전(`us-central1`)을 가이드. callable() 시그니처도 2파(수동 `.data` 언랩 vs 자동 언랩+익명인증).
- **users 조회 폴백**: 8앱 전부 구현돼 있으나 순서가 2파(name 우선 5벌 vs 규약대로 ID 우선 3벌 — 동명이인 시 서로 다른 계정으로 로그인). Betting 관리자 화면 조회는 폴백 자체가 없음(`getUserByName` 단독).
- **seoulWeekKey 6벌·payWeekKey 3벌**(테스트 0, 주석이 서로를 순환 참조) · KST 하루 키 계산 3가지 기법 병존.
- **global.css 5벌 97% 동일**, LoginPage 3벌 문구만 다름, useRunner/useBusy 훅 4벌(한 리포 안에 3벌인 곳도).
- **admin 게이트**: GameHub 함수만 `toLowerCase()` 누락. 백엔드 이메일은 4개 리포에 하드코딩(계정 추가 = 4리포 재배포).

## 관리자 기능 분산 지도 → Hub 흡수 순위

1. **P/DP 지급·회수** — ⟨브랜치해소⟩ 이번에 Hub 로 통합 (Betting·DP 철거, GameHub 좋아요 승인·Stock mint 는 잔류)
2. **승인·중재 인박스** — Board(분쟁·봉사·테스터) + DP(교환 승인) + Hub(주문 큐) + GameHub(좋아요 승인): 4앱 7큐가 전부 "대기 목록 → 승인/거부" 동형. Hub 통합 인박스 1개로 흡수 가능(콜러블은 그대로)
3. **계정 관리(생성·이름/PIN 수정·이체)** — Betting 단독 보유. 이름 변경은 6앱 로그인에 영향을 주는 크로스앱 액션인데 한 앱 관리자에만 존재
4. **하우스풀·총량 감사 뷰** — Stock·Gamble·DP 에 조각조각. P1 해결과 함께 Hub 대시보드로
5. **파라미터 보드(meta/\*)** — 4앱 전부 "단일 meta 문서 편집" 동형 UI
6. **팀 운영** — 상장·멤버(HK_Stock) vs 금고·주문(Hub)으로 한 도메인이 쪼개져 있음
